## 📁 Estructura del Repositorio 

Este repositorio está organizado para mejorar tu experiencia de aprendizaje estructurando los recursos en lecciones semanales. Cada semana se enfoca en un tema específico, construyendo sobre los conceptos aprendidos previamente:

- **Carpetas Semanales (`weeks/`)**: Cada carpeta representa una semana de entrenamiento e incluye:
  - **`README.md`**: Una descripción detallada de los temas semanales, instrucciones de configuración, objetivos y metas.
  - **`lab.ipynb`**: Un notebook interactivo paso a paso diseñado para la práctica práctica de los temas y entrenamientos semanales.
  - **`quiz.md`**: Un breve cuestionario para probar tu comprensión de los conceptos de la semana.
  - **`assets/`**: Presentaciones, documentación y materiales complementarios.

- **`src/`**: Código reutilizable y modular para ejercicios y proyectos a lo largo de las cinco semanas.

> **Nota**: Visita el [CURRÍCULO](./CURRICULUM.es.md) para un plan detallado semana por semana.

## 🚀 Comenzando

**1. Haz fork del repositorio**:
   - Haz clic en el botón "Fork" en la parte superior derecha de la página del repositorio en GitHub.

**2. Clona tu repositorio forkeado**:
   ```bash
   git clone https://github.com/tunombredeusuario/azure-ai-engineering-5-weeks.git
   ```
**3. Navega a la carpeta de la semana en la que estás trabajando**:
   ```bash
   cd azure-ai-engineering-5-weeks/weeks/week-1
   ```
**4. Sigue las instrucciones**:
   - Abre el archivo `README.md` en la carpeta para obtener instrucciones detalladas.
   - Explora y ejecuta los notebooks interactivos (`notebook_inclass.ipynb`).

**5. Inicia tu proceso de aprendizaje**:
   - Trabaja con los materiales y completa las tareas (`notebook_homework.ipynb`) para reforzar tu comprensión.
